    HOW IT FITS TOGETHER

    One page, self-contained

    1. Each sheet prints its puzzle into a QR square, along with the number of answer rows and what the puzzle is worth.
    2. Nothing is stored here. A sheet can be graded on any machine running this app, in any order, months later.
    3. The Answer sheets tab reads that square, solves the board itself to find the shortest route, then reads the handwriting and checks it.
    4. Print at 100% scale. The four corner squares are how a photo gets straightened, so they must stay on the page.
